# noncodingdrivers-test-datasets

Public test datasets for the noncodingdrivers pipeline ([Khalofx/noncodingdrivers](https://github.com/Khalofx/noncodingdrivers)).

Everything here is synthetic or public reference data. No patient or donor-level data is ever committed.

## Use in the pipeline

The pipeline's test profiles read these files over HTTPS:

```groovy
params.pipelines_testdata_base_path = 'https://raw.githubusercontent.com/Khalofx/noncodingdrivers-test-datasets/main/'
```

Module and subworkflow tests keep their own small fixtures in the pipeline repository (`tests/data/`).

## Regenerating the synthetic cohort

```bash
python3 scripts/make_synthetic_tert.py hg38.fa hg38.fa.fai data/synthetic_tert
```

`hg38.fa` must be the UCSC-style (chr-prefixed) GRCh38 FASTA with its `.fai` index. The script is deterministic: the same FASTA gives byte-identical files.

The OncodriveFML genome archive is rebuilt from a `genome_hg38_chr5_head/` directory holding the truncated `chr5.txt`:

```bash
python3 scripts/pack_genome.py genome_hg38_chr5_head data/synthetic_tert/oncodrivefml/genome_hg38_chr5_head.tar.gz
```
