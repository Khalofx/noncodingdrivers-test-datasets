# noncodingdrivers-test-datasets

Public test datasets for the noncodingdrivers pipeline ([Khalofx/noncodingdrivers](https://github.com/Khalofx/noncodingdrivers)).

Everything here is synthetic or public reference data. No patient or donor-level data is ever committed.

## Use in the pipeline

The pipeline's test profiles read these files over HTTPS:

```groovy
params.pipelines_testdata_base_path = 'https://raw.githubusercontent.com/Khalofx/noncodingdrivers-test-datasets/main/'
```

Module and subworkflow tests keep their own small fixtures in the pipeline repository (`tests/data/`), except the input-harmonisation modules (`ASSEMBLYCHECK`, `MAF2VCF`), which read the FASTA windows in `data/synthetic_tert/harmonisation/`.

## Regenerating the synthetic cohort

```bash
python3 scripts/make_synthetic_tert.py hg38.fa hg38.fa.fai data/synthetic_tert
```

`hg38.fa` must be the UCSC-style (chr-prefixed) GRCh38 FASTA with its `.fai` index. The script is deterministic: the same FASTA gives byte-identical files.

The OncodriveFML genome archive is rebuilt from a `genome_hg38_chr5_head/` directory holding the truncated `chr5.txt`:

```bash
python3 scripts/pack_genome.py genome_hg38_chr5_head data/synthetic_tert/oncodrivefml/genome_hg38_chr5_head.tar.gz
```

The input-harmonisation fixtures are rebuilt from `mutations.tsv` and the two FASTA windows
(`table_to_vcfs.py` from the pipeline repository, run with pandas available; bgzip and tabix the VCFs afterwards):

```bash
python3 scripts/build_harmonisation_fixtures.py data/synthetic_tert/mutations.tsv data/synthetic_tert/harmonisation \
    data/synthetic_tert/harmonisation/GRCh38.chr5_1-1400000.fa data/synthetic_tert/harmonisation/hg19.chr5_1-1400115.fa \
    <pipeline>/benchmarks/table_to_vcfs.py
for v in data/synthetic_tert/harmonisation/vcf/*.vcf; do bgzip -f "$v" && tabix -f -p vcf "$v.gz"; done
```

SYNTH-NC (`data/synth_nc/`) is regenerated with:

```bash
python3 scripts/make_synthetic_cohort.py --fasta hg38.fa \
    --elements GRCh38_regulatory_build.ccre.noncoding.v50.bed --cadd whole_genome_SNVs.tsv.gz \
    --out-maf data/synth_nc/SYNTH-NC.maf.gz --out-truth data/synth_nc/SYNTH-NC.truth.json \
    --seed 20260923 --donors 60
```
